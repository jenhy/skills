# GLOSSARY.md 格式

`GLOSSARY.md` 放在工作空间根目录，是这个教学工作空间的**标准用语**。所有课程、参考资料、学习记录都必须遵守它的术语——写词条定义时，也要用表内的词。

建术语表本身就是学习的一部分：把一个概念压缩成一句紧的定义，是用户已经理解的证据。

## 模板

```md
# {主题} 术语表

{一两句话，说明这个术语表覆盖的主题。}

## 术语

**肌肥大**：
由反复训练中的机械张力与代谢压力驱动的肌肉生长。
_避免_：增肌、变壮

**渐进超负荷**：
通过负荷、训练量或强度，系统性地提升对肌肉的要求。
_避免_：练得更狠、升级

**RPE（自觉用力程度）**：
一组训练有多难的自评分，1–10 分，10 分是力竭，8 分表示还剩两次。
_避免_：努力评分、强度评分
```

## 规则

- **只在用户已经理解之后才收录。** 术语表是压缩知识的记录，不是供用户阅读学习的词典。刚介绍过的概念先别写，等他能正确使用这个词再收。
- **要有主见。** 同一个概念有好几种说法时，选最好的那个，其余列为 `_避免_` 的别名。语言就是这样压缩下来的。
- **定义要短。** 一两句话。说清这个词**是什么**，不是它做什么、怎么做。
- **定义里要用术语表自己的词。** 一个词进了表，所有地方都用它，包括在其他词条的定义里。复杂术语就是这样变得好懂的。
- **成簇就用子标题分组。** 术语自然聚集时（如 `## 解剖`、`## 训练编排`）分组；数量少且内聚时，平铺即可。
- **把歧义标出来。** 某个词在更广的领域里被松散使用，就注明本工作空间的约定：「在本工作空间，『组』一律指正式组，热身单独计。」
- **随理解加深就地修订。** 第一周写的定义，第六周可能已经错了。就地改，不要留过期词条。

## 与学习记录的分工

这两个文件最容易混，分工是：

- `GLOSSARY.md` 记**稳定的术语**——长期不变的标准用语
- `./learning-records/` 记**认知的变化**——什么时候学会了什么、什么被推翻了

一个词条的定义被大幅修订时，除了就地改 `GLOSSARY.md`，还值得在 `./learning-records/` 留一条记录说明为什么改。
