# Learn：10x 学习加速器

用 6 个串联工具，以 10 倍速度学习任何技能或概念。

## 30 秒安装

```bash
npx skills@latest add mattpocock/skills
```

安装后在 Claude Code 中输入 `/learn` 即可使用。

## 使用

```
/learn
```

然后告诉 Claude 你想学什么。6 个工具按顺序启动：

1. **学习阶梯**：5 级地图，看清全景
2. **信号筛选**：只保留最值得看的资源
3. **20 小时学习法**：抓核心 20%，排实战计划
4. **费曼检验**：用 12 岁小孩能懂的话讲出来
5. **AI 考官**：渐进式考试，找到知识盲区
6. **一页速查表**：全主题压缩到一页可打印 HTML

## 依赖

无外部依赖。自包含 skill，无需安装 `teach`。

## 更新

```bash
npx skills@latest update
```
