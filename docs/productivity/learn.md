## What it does

Learn 让你以 10 倍速度掌握任何技能或概念。它把六种学习工具串联成一条端到端流水线，在当前目录下构建一个自包含的教学工作空间，产出课程 HTML、参考资料、学习记录和一页速查表。

定义它的那条约束是：**Learn 不是聊天式教学，而是有状态的流水线**。六步（学习阶梯、信号筛选、20 小时学习法、费曼检验、AI 考官、一页速查表）各有明确的入口和产出，进度全部落在工作空间的文件里，所以你可以随时中断、隔几天回来、继续。

## When to reach for it

- **调用方式**：输入 `/learn <你想学什么>`。agent 不会自行触发它，需要你主动调用。
- **何时使用**：想快速入门一个新主题、系统提升已入门领域的水平、或从零做到能拿出项目级输出。Learn 把你从「不知道从哪下手」直接推到「能用、能讲、能查」。

如果你要的是**开放式、按自己节奏走的陪伴式教学**，用 [teach](https://aihero.dev/skills-teach)。两者共用同一套工作空间文件格式，区别在结构：teach 由 agent 当老师，按你的反馈决定下一步教什么；learn 跑的是固定六步流水线，每一步都有预设的入口和产出。

## The six tools

Learn 的核心流水线由六个工具组成，按顺序执行：

1. **学习阶梯**：画出领域全景 5 级地图，定位你当前在哪、想到哪，路径一目了然。新手支线先看全景再定位，有基础支线先定位再定制，项目驱动支线以终为始。

2. **信号筛选**：从海量材料中捞取真正值得看的那几份，每一份都告诉你「别看哪里」。同时给出按天编排的学习路径。

3. **20 小时学习法**：提炼核心 20% 内容（能撬动 80% 效果），拆成精确到每次的学习 session。每次 session 的四个要素（学什么、练什么、用什么资源、复盘什么）都是你从多个选项中选择确认的。

4. **费曼检验**：每节 lesson 学完后，用自己的话讲给「12 岁小孩」听。AI 诊断你讲对了什么、漏了什么、混淆了什么、用了但没懂的词，只重新解释你没真懂的部分。

5. **AI 考官**：一个阶段结束后，渐进式压力测试，从记忆到理解到应用再到批判，一次一题，每题实时评分加诊断，最后给出综合评估和精准复习路径。

6. **一页速查表**：全部学完后，把整个主题压缩到一张可打印的 HTML 页面，按你的使用场景（面试、考试、演讲、日常查阅、教别人、项目实战）定制内容结构。

## The workspace

Learn 在当前目录下构建一个完整的教学工作空间：

- `MISSION.md`：你的学习目标和阶梯表
- `RESOURCES.md`：筛选后的高价值资源
- `NOTES.md`：偏好、计划、临时笔记
- `./lessons/*.html`：自包含的交互式课程文件
- `./reference/*.html`：语法速查、术语表、速查表
- `./learning-records/*.md`：费曼诊断和考试成绩记录
- `./assets/*`：跨课程复用的样式表、测验组件等

一切可复用组件都抽到 `assets/` 下，课程永远引用共享资产而非内联重复代码。每节课都绑定使命、处于最近发展区、短小但给用户可感知的收获。

## Common questions

**learn 和 teach 到底什么区别？我该用哪个？**

区别不在工作空间，两者写的是同一套文件（`MISSION.md`、`lessons/`、`learning-records/`、`reference/`、`assets/`）。区别在**谁决定下一步**：teach 里是 agent 当老师，根据你的反馈和最近发展区现场判断教什么；learn 跑的是固定六步，每一步有预设入口和产出。想要开放式的、按你节奏走的陪伴式教学，用 teach；想要一条从零到能用的既定路线，用 learn。

**我学完一节、隔几天回来，它还记得我学到哪了吗？**

记得。每次进入 learn，第一件事是扫工作空间判断当前在哪一环（有没有使命、有没有阶梯表、有没有 session 计划、最近一节有没有做费曼检验），然后把判断结果说给你听，再问你是接着走还是跳步。判断依据全部来自文件，不依赖对话历史。

**它问我想学这个是为了什么，我不想回答会怎样？**

它会留着不填。Learn 的规则是使命必须来自你本人，不允许 agent 凭印象替你编一个听起来合理的。你如果没回答，`MISSION.md` 的 `## Why` 会留成待答状态，它会明确告诉你课程在等你的回答，而不是先编一个目标把后续课程都挂上去。

**测验的答案能不能靠选项长度猜出来？**

不能。Learn 的 SKILL.md 明确要求客观题的每个选项字数相同（能凑到字符数一致更好），因为长度、措辞、格式上的任何差异都在泄题，会让人靠排除法而不是靠理解作答。

## It's working if

- 从第二节课开始，它不再问「你是完全新手还是有基础」，而是直接说「你上次学到第 3 节，还没做费曼检验」。
- `MISSION.md` 里的 `## Why` 是你自己说过的话，不是你从没讲过的一句听起来合理的目标。
- 每节课都是能直接打开、能打印的独立 HTML，且都链接同一份共享样式表。
- 你答错时它只重讲你没掌握的那部分，而不是把整节课从头再来一遍。
- `learning-records/` 里的条目写的是「已确认他会 X」，不是「今天讲了 X」。

## Where it fits

Learn 是一个**独立的启动入口**：随时 `/learn <主题>` 就能开始，不依赖其他 skill。

它的邻居是 [teach](https://aihero.dev/skills-teach)：teach 是同一套教学工作空间的开放式用法，agent 当老师、按你的反馈决定教什么；learn 是固定六步的结构化流水线。需要开放式陪伴教学选 teach，需要既定路线选 learn。

如需了解整套 skill 体系的完整地图，参考 [ask-matt](https://aihero.dev/skills-ask-matt)。
